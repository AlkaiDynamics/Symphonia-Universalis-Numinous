# Symphonia Universalis Numinous (SUN)

Versioned research archive for the recovered SUN lineage and the current V3 hypergraph coverage baseline.

Start with [`VERSION_INDEX.md`](VERSION_INDEX.md).

## Repository principles

- **Music is the fixed reference object.** SUN versions are formal accounts of the music-native structure; they are not allowed to rewrite the underlying evidence.
- **Models, music, and cross-domain adapters are separate layers.**
- **Historical gaps stay gaps.** Missing V1-A/V1-B standalone material is not fabricated from later summaries.
- **V1-D is the locked test harness.**
- **V2 remains a candidate, not a replacement of V1-D.**
- **V3 is the current hypergraph prior-art/coverage branch.** Its coverage pass is complete, while source recovery remains incomplete and broad P0 remains open.

The authoritative recovered mutation chronology is in [`history/SUN_AUTHORITATIVE_MUTATION_CHRONOLOGY_2026-10-01.md`](history/SUN_AUTHORITATIVE_MUTATION_CHRONOLOGY_2026-10-01.md).
